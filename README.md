# DriveSafe AI – Driver Fatigue Detection System

## About the Project

DriveSafe AI is a browser-based Artificial Intelligence system developed as a group project during the CAPACITI AI Bootcamp.

The project addresses driver fatigue through real-time computer vision and image classification. Using a webcam, the system monitors a driver's facial cues, classifies their alertness state, and provides audio alerts when signs of fatigue are detected.

The system was developed as a transportation-sector AI solution using browser-based technologies and no-code machine learning tools.

## Project Objectives

- Detect signs of driver fatigue in real time
- Monitor driver alertness using computer vision
- Classify different driver states
- Provide audio alerts when fatigue is detected
- Support safer driving through early fatigue warnings

## Key Features

- Real-time eye tracking
- Neural fatigue scoring
- Instant audio alerts
- Head pose analysis
- Yawn detection
- Trip safety reports
- Real-time driver state classification
- Fatigue alerts and response options

## Driver States

The system classifies the driver into five states:

- Focused
- Tired
- Yawning
- Asleep
- Not Focused

Each state produces an appropriate system response depending on the detected level of fatigue.

## How It Works

1. The driver opens the DriveSafe AI web application.
2. The system requests camera permission.
3. The webcam begins capturing frames.
4. The AI model analyses facial features and driver alertness.
5. The system classifies the driver's current state.
6. The dashboard updates the driver's status and confidence score.
7. If fatigue is detected, an appropriate alert is triggered.
8. Fatigue events are recorded for the trip safety report.

## Challenges & Limitations

The project documentation identifies several limitations:

- Detection can be affected by poor lighting conditions.
- The training dataset was relatively small.
- The model was produced from a single training session.
- Trip reports and event logs were not persisted to a cloud backend.
- A more diverse training dataset would be needed to improve generalisation.

## Ethical Considerations

The project considered:

- User privacy
- Camera permission and informed consent
- AI bias
- Responsible use of driver monitoring data

The system is intended to supplement existing road-safety practices rather than replace driver judgement, adequate rest, or rest-hour regulations.
